### 3.6.2. Memoria del proyecto

**Nombre del proyecto:** DraftWEAR  
**Tipo:** Tienda Online Full-Stack  
**Enlace:** [https://github.com/Rubinzo/ProyectoDAW](https://github.com/Rubinzo/ProyectoDAW)

**DraftWEAR** es una aplicación web de comercio electrónico que permite a los usuarios registrarse, explorar un catálogo de camisetas de fútbol, añadir productos al carrito y gestionar compras básicas.

**Tecnologías utilizadas:**

**Frontend:**
- HTML5
- CSS3 (Flexbox y Grid)
- JavaScript (Vanilla ES6+)
- Diseño responsive

**Backend:**
- Java 21 + Maven
- HttpServer (Java)
- PostgreSQL + JDBC
- Gson para JSON

**Otras tecnologías:**
- XML (catálogo de productos)
- Git + GitHub (ramas: `main`, `FrontDevelop`, `BackDevelop`, `FeaturesCSS`)

**Estructura del repositorio:**
- Rama `FrontDevelop` → Versión más completa del frontend (recomendada)
- Ramas `BackDevelop` y `BackDevellop` → Backend en Java con conexión a base de datos
- Rama `FeaturesCSS` → Mejoras de diseño y estilos

### 3.6.4. Reflexión final

La realización de este proyecto ha sido una de las experiencias más enriquecedoras de mi formación en Desarrollo de Aplicaciones Web.

Haber desarrollado **DraftWEAR** de principio a fin me ha permitido integrar todos los conocimientos adquiridos: desde el diseño de interfaces hasta la creación de un backend conectado a una base de datos.
