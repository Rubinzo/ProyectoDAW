## 4. Presentación profesional del proyecto

**DraftWEAR** es una tienda online desarrollada como Proyecto Intermodular de 1º DAW.

**¿Qué problema resuelve?**  
Proporciona una plataforma moderna y accesible para comprar ropa (enfocada en streetwear y camisetas) de forma cómoda desde cualquier dispositivo.

**¿Para quién está pensado?**  
Principalmente para jóvenes interesados en moda urbana y deportiva que buscan una experiencia de compra atractiva y funcional.

**Tecnologías utilizadas (mi contribución principal):**  
- **HTML5**  
- **CSS3** (Flexbox, Grid y diseño responsive)  
- **JavaScript Vanilla** (DOM, eventos, carrito, filtros, etc.)

**¿Qué he aprendido desarrollándolo?**  
He mejorado mucho mi capacidad para estructurar proyectos, crear interfaces dinámicas, trabajar con Git en equipo y escribir código limpio y mantenible.

## 6. Reflexión personal

Este primer Proyecto Intermodular ha sido una experiencia muy positiva. Me ha gustado especialmente trabajar en el **Frontend**, creando las interfaces y haciendo que todo sea dinámico con JavaScript.

Lo que mejor se me ha dado ha sido el diseño y las interacciones visuales. Lo que más me ha costado ha sido coordinar el trabajo con el backend y resolver algunos problemas de responsive en diferentes tamaños de pantalla.

**Qué mejoraría del proyecto:**  
- Mejorar la seguridad de las entradas de usuario  
- Optimizar el código y hacerlo más escalable  
- Conectar mejor el frontend con el backend
